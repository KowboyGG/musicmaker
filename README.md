# MusicMaker

Генератор музыки для игр и видео. Работает прямо в браузере: без сервера, без регистрации, без платных API.

Выбираете жанр и набор инструментов («блоков»), нажимаете «Сгенерировать», слушаете и правите. Готовый трек можно скачать как WAV (целиком или бесшовным лупом для игры), разложить на стемы или открыть как MIDI в своей DAW.

## Что умеет

- **18 жанров:** эпик и трейлер, экшен, синтвейв, 8-бит, фэнтези, уютное меню, эмбиент, лоу-фай, хаус, трэп, рок, поп, хоррор, стелс, джаз, таверна (в том числе вальс 3/4), Восток, грустное пианино.
- **Блоки:** ударные, бас, аккорды, пэд, арпеджио, мелодия, подголосок, эффекты. Блоки можно включать и выключать, менять им инструменты и добавлять новые.
- **Структура:** луп на 8 или 16 тактов (A + B), короткая (~30 сек), средняя (~1–1,5 мин) или длинная (~2–3 мин) песня: вступление, куплет, подводка, припев, бридж, финальный припев, концовка.
- **Теория музыки внутри:** лады, жанровые прогрессии, голосоведение, мелодии из мотивов с «вопросом и ответом», сбивки ударных, кривая энергии. Подробности в [docs/THEORY.md](docs/THEORY.md).
- **Редактор:** сетка «дорожки × секции», пианоролл с подсветкой звуков аккорда, сетка ударных, аккорды по тактам. «Новая партия» перегенерирует одну дорожку в секции, а «Вся секция заново» — всю секцию.
- **Развить идею:** нарисуйте пару тактов (ритм, мелодию или бас) и нажмите кнопку. Набросок станет припевом, а генератор подберёт аккорды и достроит остальную песню в выбранном жанре.
- **Правки через ИИ:** кнопка «JSON и ИИ» → «Скопировать для ИИ» кладёт в буфер обмена инструкцию к формату и саму песню. Вставляете в чат (Claude, ChatGPT…), пишете, что поменять, ответ вставляете обратно и жмёте «Применить». Формат описан в [docs/FORMAT.md](docs/FORMAT.md).
- **Экспорт:** WAV, WAV-луп (хвост реверберации переносится в начало, склейка бесшовная), стемы ZIP (каждая дорожка отдельным лупом — для вертикального наслоения в игре), MIDI, JSON.
- Отмена и возврат (Ctrl+Z / Ctrl+Shift+Z), автосохранение в браузере, пробел — играть или стоп.

## Как запустить

Сайт статический: нужны только файлы из репозитория. Браузер не загружает модули через `file://`, поэтому откройте его одним из способов.

**GitHub Pages (проще всего, будет постоянная ссылка):**
1. Влейте ветку в `main`.
2. В репозитории откройте Settings → Pages → Build and deployment → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу вида `https://<ваш-логин>.github.io/musicmaker/`.

**Локально** (нужен Node.js или Python):

```bash
npx http-server -c-1 .      # затем откройте http://localhost:8080
# или
python -m http.server 8080
```

Нужен современный браузер: Chrome, Edge, Firefox или Safari последних версий.

## Как пользоваться

1. Слева выберите жанр, настроение, длину и блоки. Нажмите «Сгенерировать песню», затем «Играть».
2. Не понравилось — жмите ещё раз. Понравился вариант — запомните его номер (seed): он повторит ту же песню.
3. Кликните по клетке сетки, чтобы открыть партию в редакторе снизу. Двойной клик по секции играет песню с этого места, режим «Секцию по кругу» зацикливает одну секцию.
4. Для игры выберите длину «Луп» и экспортируйте «WAV-луп» или «Стемы».

## Ограничения

- Звук синтезируется в браузере. Электроника, 8-бит, эмбиент, оркестровые фоны и синтвейв звучат хорошо. «Живые» инструменты (перегруженная гитара, реалистичные барабаны) звучат упрощённо. Для студийного качества экспортируйте MIDI и подставьте свои инструменты в DAW.
- Вокала и текста нет.
- Генератор делает добротную фоновую музыку, а не хиты. Характер треку придают ваши правки: руками или через ИИ.

## Устройство

```
index.html            страница
css/app.css           оформление (тёмная и светлая тема)
js/core/              теория музыки, формат песни, таймлайн, инструкция для ИИ
js/gen/               генератор: жанры, грувы ударных, мелодии, партии, сборка песни
js/audio/             синтез инструментов и ударных, микшер, проигрыватель, офлайн-рендер
js/export/            WAV, MIDI, ZIP
js/ui/                интерфейс: сетка, пианоролл, сетка ударных
tests/                юнит-тесты (node) и сквозной тест в браузере (Playwright)
docs/                 формат JSON и заметки по теории
```

Тесты:

```bash
npm test                    # логика: теория, формат, генератор во всех жанрах
npm run test:browser        # браузер: генерация, звук, редактор, JSON, экспорт (нужен Playwright)
```
